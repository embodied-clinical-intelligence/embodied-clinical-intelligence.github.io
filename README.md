# Embodied Clinical Intelligence

Landing page for the UC Berkeley-UCSF Embodied Clinical Intelligence Colloquium.

## About

A community of researchers at the intersection of AI and medicine that are unequivocally technical yet uncompromisingly clinical, seeking to develop embodied AI systems grounded in the complexities of clinical care.

## Development

Open `index.html` in a browser. For full functionality (canvas-based features), serve locally:

```
python3 -m http.server
```

## Deployment

Hosted via GitHub Pages at [embodied-clinical-intelligence.github.io](https://embodied-clinical-intelligence.github.io).
